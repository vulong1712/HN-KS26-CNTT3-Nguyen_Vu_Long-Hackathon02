# GREENFIELD

## Hệ thống dùng để quản lý **Website đặt sân bóng mini**,hệ thống giúp **đặt sân**, *bóng đá mini*

## Hệ thống thư mục của web
| Thư mục | Nội dung |
| :---: | :---: |
| docs | ghi chú những dữ liệu của khách hàng |
| data | bảng tính lưu trữ danh sách đặt sân tháng 10 |
| logs | Ghi lại lưu trữ nhưng sự cố lỗi của hệ thống |

## Lệnh liệt kê nội dung dự án
```powershell
Get-ChildItem -Recurse -Force
```
